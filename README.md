# 🩺 Voice Prescription System

A web-based healthcare application that enables doctors to generate digital prescriptions using voice commands. The system converts spoken medical information into text using speech recognition technology, allowing doctors to review, edit, and securely save prescriptions. The application reduces manual documentation, improves prescription accuracy, and simplifies healthcare workflows.

---

## 📌 Features

- 🎤 Voice-to-Text Prescription Generation
- 📝 Manual Editing and Validation of Prescriptions
- 👨‍⚕️ Doctor Dashboard
- 👨‍💼 Admin Dashboard
- 👥 Patient Management
- 💊 Medicine and Prescription Management
- 🔐 JWT-Based Authentication & Role-Based Access Control
- 📊 Dashboard for Managing Doctors and Patients
- 💾 Secure Storage of Patient Records using MySQL
- 🔄 RESTful API Integration
- 📱 Responsive User Interface

## 🔄 System Workflow

1. User Login
2. Authentication using JWT
3. Role Selection (Doctor/Admin)
4. Doctor selects patient
5. Create prescription
6. Voice input converted to text
7. Doctor validates the prescription
8. Store prescription in MySQL database
9. Dashboard updated
10. Logout
